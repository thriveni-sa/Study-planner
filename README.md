# 📚 Study Planner

A simple and user-friendly Study Planner web application designed to help students organize their study schedules, manage tasks, and stay focused on their academic goals.

## ✨ Features

- 📅 **Study Planning** – Organize study activities and plan your learning schedule.
- ✅ **Task Management** – Keep track of study tasks and activities.
- 🎯 **Stay Organized** – Manage academic priorities in one place.
- 💻 **Simple Interface** – Easy-to-use design for students.
- 📱 **Responsive Design** – Designed to provide a convenient experience across screen sizes, if supported by the implementation.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

### 1. Clone the repository
